Help & FAQ

How to use ZenoChat AI

1. Enter your API key in the settings (Hugging Face or Groq).

2. Go to the Chat page and start typing.

3. Use the voice button for voice-to-text.

Multi-language Support

ZenoChat AI supports multiple languages. By default, it uses Hinglish (Hindi + English), but you can ask it to respond in:

  • English (Professional/Casual)
  • Hindi (Pure/Sarkari)
  • Spanish, French, German, and more.

Privacy & Data Security

1. Data Sovereignty

ZenoChat AI operates on a decentralized data model. Your conversations, API keys, and preferences are stored exclusively within your browser's Local Storage. We do not maintain any central servers that store your personal data.

2. API Communication

When you interact with the AI, your messages are sent directly to the selected provider (Hugging Face or Groq). This connection is secured via industry-standard SSL/TLS encryption. Your API key is used only to authenticate these requests and is never shared with any other third party.

3. Localized Memory

The "Conversation Memory" feature works by retrieving your past messages from your local device to provide context to the AI. This process happens entirely on the client side. Clearing your browser cache or deleting chats within the app will permanently remove this data.

4. No Tracking

We do not use cookies, pixels, or any third-party analytics scripts to track your behavior. ZenoChat AI is a privacy-first application designed to provide a clean, secure, and focused AI experience.

Security Assurance

By using ZenoChat AI, you retain full control over your data. For maximum security, we recommend never sharing your API key and using the application in a secure, private browser environment.
